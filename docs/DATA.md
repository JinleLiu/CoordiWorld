# Data access

No study numerical data is distributed in the public code repository: this includes individual scene/drive records, per-mapping results/plans, empirical feature fixtures and aggregate result tables. Official NAVSIM/OpenScene logs, images and maps are obtained from their providers and are not redistributed here.

The accompanying numerical supplement separately supplies anonymous paired evidence for the validated core replay. Its README explains how to overlay the files on this repository and run `scripts/replay_supplement.py`. The private mapping back to raw source identifiers is not included. The supplement has three-cohort saved mapping records, drive event sufficient statistics and 1,280 original-anchor risk predictions/labels/weights, together with the real main-readout fixture.

Complete TRAIN240 feature matrices and later portable readout-control weights are outside the public code release and the small numerical supplement. Their research source can be inspected, but executing every study requires the relevant additional artifacts.
