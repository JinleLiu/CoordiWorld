# Use and inspect the publication copies

Use the top-level CPU and figure entry points for the tested saved-result operations. `source/` holds complete historical implementations; `selection/` holds deliberately smaller portable components. Complete-source availability does not imply an independently reconstructed raw-to-result inference environment.

The seven newly included full files retain eligibility, fallback, controller, H3/P0, guard and history propagation branches. Special-case scene constants are replaced with `publication_identifier(key)` lookups in `config/source_identifiers_v12a.json`. The mapping is consistent with the numerical attachment. Set `COORDIWORLD_IDENTITY_CONFIG` to an explicitly authorized alternative mapping when restoring original-environment assets; the private original mapping is not distributed. Keys and branch predicates are retained, with no empty replacement functions.

Historical source import paths require `paper_revision/source` on `PYTHONPATH` plus the original archive layout and native/model packages. Affected root providers and complete source entries call `publication_path()` for `<CW_WORKSPACE>` or `${CW_ARCHIVE_ROOT}`; supply these named roots as absolute environment paths. No machine-specific path fallback is supplied. Other archived source paths remain logical provenance references. Runtime code/source SHA checks and historical execution deadlines are retained; no source hash is spoofed and no assertion is disabled. The three `frozen/` copies are historical evidence, not a new validated runtime lock for the transformed bytes. Full inference adaptation and testing remain outside this release.

`SOURCE_INDEX.csv` retains origin aliases and original/delivered/v12/publication hashes. `SOURCE_PUBLICATION_BINDINGS_v12a.json` gives exact original-to-publication bindings. Private full packaging diffs are retained for author review because their removed lines contain original identifiers. The public transformation summary and complete-source AST restoration checks describe the packaging; they do not assert full inference equivalence.

Scene and drive aliases are fixed-width and monotonic in the original lexical order. This preserves the original replay's sorted-token and sorted-drive bootstrap ordering. Row order, method pairing, predecessors, formal/auxiliary membership, all numeric field strings, missing values and failures remain unchanged. Training hash ranks, original order and selection basis are preserved; aliases never cause a new selection. Original and publication SHA values are separately recorded, and all operational integrity checks pin the actual provided bytes.

The sole v12 plot script has only route identifier string substitutions. Full-precision plot inputs preserve controls, time fields, first-divergence anchor, display ordering and case outcomes. Fig. 3 and the former Fig. 4 use no alternative interpolation or new image-generation procedure. Font files and private reverse maps are excluded.
